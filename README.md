# 🚀 Farhan Akhtar — Portfolio

A sleek, animated personal portfolio website built with **HTML/CSS/JavaScript** and an **Express.js** backend.

![Black & Red Theme](https://img.shields.io/badge/Theme-Black%20%26%20Red-ff2d2d?style=for-the-badge)
![Node.js](https://img.shields.io/badge/Node.js-Backend-339933?style=for-the-badge&logo=node.js&logoColor=white)
![Express](https://img.shields.io/badge/Express-API-000000?style=for-the-badge&logo=express&logoColor=white)

## ✨ Features

- 🎨 **Dark theme** with black, white & red color palette
- 🎬 **Smooth animations** — scroll reveals, 3D card tilt, floating particles, custom cursor
- 📊 **Live visitor counter** via backend API
- 📩 **Working contact form** — messages saved server-side
- 📱 **Fully responsive** — mobile-friendly design
- ⚡ **REST API** with 5 endpoints

## 💡 Featured Projects

- 📷 **CCTV AI — Student Mobile Phone Detection**: Real-time classroom surveillance detecting mobile phone usage with YOLOv8 & OpenCV.
- 💬 **RealTime Chat App (WhatsApp Style)**: Instant messaging app with online presence, typing status, and room support using Socket.io & React.
- 📱 **Real-Time Mobile Screen Share**: Low-latency peer-to-peer screen streaming from mobile to any browser using WebRTC.
- 🐍 **Neural Network Plays Snake Game**: Deep reinforcement learning agent trained with PyTorch that learns to play Snake and adapt new strategies.

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Data:** JSON file storage

## 🚀 Run Locally

```bash
npm install
node server.js
```

Open **http://localhost:3000** in your browser.

## 📡 API Endpoints

| Method | Route | Description |
|--------|-------|-------------|
| GET | `/api/status` | Server health check |
| GET | `/api/profile` | Profile data |
| GET | `/api/visitors` | Visitor counter |
| POST | `/api/contact` | Submit contact form |
| GET | `/api/messages` | View all messages |
